    About Us

    What BloxBeacon is, who it is for and how its guides are put together.

    Our purpose

    BloxBeacon is an independent fan resource for Roblox players and creators. The main focus is Roblox Codes: one page per game, listing active and expired codes, the reward for each, and how to redeem them.

    The Roblox Scripts section is separate. It concentrates on Luau tutorials for Roblox Studio, and labels anything involving third-party tools along with the risks.

    How guides are meant to work

    • Each code guide shows when its codes were last checked.
    • Codes that stop working are moved to the expired list rather than deleted.
    • Script guides state their requirements and include safety notes. We do not describe a script as safe unless that has been verified.

    This is a preview build

    The site currently contains sample content only. The games are placeholders and the codes, rewards and dates are not real. There is no live data feed, database or admin dashboard connected yet.

    Independence

    BloxBeacon is not affiliated with, sponsored by or endorsed by Roblox Corporation.
