    What is BloxBeacon?

    BloxBeacon is a fan-made guide site for Roblox players and creators. Its main job is simple: list the codes for each game, say what every code gives you, and show how to redeem it.

    The scripts section is kept separate. It focuses on Luau tutorials for Roblox Studio, and clearly labels anything that involves third-party tools so you can see the risks before you read on.

    More about us

    • Clear labelsActive and expired codes are listed separately, with the date they were last checked.
    • No account details, everWe will never ask for your Roblox password or login.
    • Honest about riskWe do not call a script safe unless that has been verified.
