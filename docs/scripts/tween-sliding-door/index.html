    Make a sliding door with TweenService

    Use a ProximityPrompt and TweenService to smoothly open and close a door part.

    Topic
    Building & animation
    Runs in
    For Roblox Studio development
    Last updated
    8 Nov 2026

    Sample article

    This is a sample tutorial included to preview the site. The script is a teaching example for Roblox Studio. Test it in your own place before relying on it.

    What this script does

    This script slides a door sideways when a player triggers a ProximityPrompt, then slides it back the next time. TweenService handles the smooth movement.

    Requirements

    • Roblox Studio and edit access to the place.
    • An anchored Part to act as the door, with a ProximityPrompt inside it.

    The script

    How to use it

    1. Create a Part for the door and tick Anchored in the Properties window.
    2. Insert a ProximityPrompt into the Part and set ActionText to Open.
    3. Insert a Script into the same Part and paste the code.
    4. Press Play, walk up to the door and hold the prompt key.

    Before you use this

    • The door must be anchored, otherwise physics will fight the tween.
    • BloxBeacon will never ask for your Roblox password or account details.
