    How to check free models for hidden scripts

    A Command Bar snippet that lists every script in your place so you can review anything you did not add.

    Topic
    Account safety
    Runs in
    For Roblox Studio development
    Last updated
    4 Nov 2026

    Sample article

    This is a sample tutorial included to preview the site. The script is a teaching example for Roblox Studio. Test it in your own place before relying on it.

    What this script does

    Free models from the Toolbox sometimes contain extra scripts you did not ask for. This snippet prints the location of every script in your place so you can open and read each one.

    It only lists scripts. It cannot tell you whether a script is harmful, so you still need to review them yourself.

    Requirements

    • Roblox Studio with the Command Bar and Output windows open (both are in the View tab).

    The script

    How to use it

    1. Open View → Command Bar and View → Output.
    2. Paste the snippet into the Command Bar and press Enter.
    3. Go through the list in Output. Open any script you do not recognise.
    4. Look for require() calls with long number IDs, getfenv, loadstring, or code that is deliberately unreadable. Delete scripts you cannot explain.

    Before you use this

    • A clean result from this snippet does not prove a model is safe. Plugins can also insert scripts, so only install plugins from creators you trust.
    • BloxBeacon will never ask for your Roblox password or account details.
