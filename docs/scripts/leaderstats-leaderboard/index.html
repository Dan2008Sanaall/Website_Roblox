    Create a leaderstats leaderboard with Coins

    A short beginner script that shows a Coins value next to each player on the in-game leaderboard.

    Topic
    Beginner basics
    Runs in
    For Roblox Studio development
    Last updated
    12 Nov 2026

    Sample article

    This is a sample tutorial included to preview the site. The script is a teaching example for Roblox Studio. Test it in your own place before relying on it.

    What this script does

    Roblox shows any values stored in a folder named leaderstats on the default player list. This script creates that folder and a Coins value whenever a player joins.

    Requirements

    • Roblox Studio and edit access to the place.

    The script

    How to use it

    1. Insert a Script into ServerScriptService.
    2. Paste the code and press Play.
    3. Open the player list in the top-right corner to see the Coins column.

    Before you use this

    • This example does not save progress. Values reset when the player leaves unless you add DataStore saving.
    • BloxBeacon will never ask for your Roblox password or account details.
