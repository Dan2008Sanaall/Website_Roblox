    How to build a redeem-code system in Roblox Studio

    A server-side Luau example that lets players redeem one-time codes for coins in your own game.

    Topic
    Game systems
    Runs in
    For Roblox Studio development
    Last updated
    14 Nov 2026

    Sample article

    This is a sample tutorial included to preview the site. The script is a teaching example for Roblox Studio. Test it in your own place before relying on it.

    What this script does

    This example adds a basic code system to a game you are building. The server keeps the list of valid codes, checks whether a player has already used one, and then adds coins to their leaderstats.

    All checks happen on the server. The client only sends the text the player typed, so players cannot grant themselves rewards by editing local scripts.

    Requirements

    • Roblox Studio and edit access to the place.
    • A leaderstats folder with a Coins value (see the leaderboard tutorial).
    • A published place with “Enable Studio Access to API Services” turned on, so DataStores work while testing.

    The script

    How to use it

    1. In the Explorer, hover over ServerScriptService, press + and insert a Script.
    2. Paste the code above into the script and edit the CODES table.
    3. Create a ScreenGui with a TextBox and a TextButton for players to type into.
    4. In a LocalScript under the button, call ReplicatedStorage.RedeemCode:InvokeServer(textBox.Text) and show the returned message.
    5. Publish the place, enable API access in Game Settings → Security, then press Play to test.

    Before you use this

    • Keep the list of codes in a server Script. Anything placed in a LocalScript or ReplicatedStorage can be read by players.
    • DataStore requests can fail or be throttled. This example reports an error instead of granting the reward, but a production game should also retry and log failures.
    • BloxBeacon will never ask for your Roblox password or account details.
