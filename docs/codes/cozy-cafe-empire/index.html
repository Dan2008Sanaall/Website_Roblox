    How to redeem Cozy Café Empire codes

    1. Open your café and tap the settings cog.
    2. Enter a code into the Promo Code field.
    3. Press Redeem.

    Codes are often case-sensitive, so copying and pasting is the safest way to enter them. If a code does not work, it may have expired or may need a newer server.

    Where to find new codes

    Developers decide when to release codes. These are the usual places to check:

    • The description on the game’s official Roblox page.
    • The developer’s official social accounts, linked from the game page.

    A real code is only ever entered inside the game. Ignore any site or message that asks for your Roblox password in exchange for codes or Robux.
